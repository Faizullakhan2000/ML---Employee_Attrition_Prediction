## How to View the Project

GitHub may not display the notebook preview correctly. To view the complete project, including the Python code and analysis:

1. Download the `Employee_Attrition_Prediction_GitHub.ipynb` file from this repository.
2. Open [Google Colab](https://colab.research.google.com/).
3. Click **File → Upload notebook**.
4. Upload the downloaded `.ipynb` file to view the code and project workflow.

**Note:** To rerun the complete project, you may also need the dataset file used in the notebook.
